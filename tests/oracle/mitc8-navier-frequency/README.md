# MITC8 laminate frequencies

Same full4x4 mesh and symmetric [0/90/90/0] layup as mitc8-navier-thin, density1600. First three FSDT branches and independent 3x3 reference are in ../composite-navier-frequency-thick/README.md. Both consistent and positive-diagonal scaled lumped masses are tested against fixed2%/5% bands.
