# mitc6a-coupled-strip

Original six-node triangular mesh, obtained by splitting the original quadrilateral geometry and adding true quadratic edge midpoints. No hidden central DOFs. 15 nodes, 4 elements. Same continuum data and tolerances as the corresponding MITC8 reference case. Sinusoidal loads, when used, are integrated against triangular quadratic shapes. Curved roof diagonal midpoints are on the exact cylinder.
