# Two-mass reciprocity

Two unit masses have grounding springs 3 and a connecting spring 2. Rayleigh alpha=0.1, beta=0.01 and structural loss eta=0.03 are additive. Interchanging the loaded and observed nodes preserves the complex response. Both direct cases and a two-mode response are checked against the independently inverted 2x2 matrix, as well as their power balances.

A one-mode basis with one load-dependent residual vector must reproduce the same closed-form response and full equilibrium. The extra vector is a static load correction, not a second reported natural mode.
