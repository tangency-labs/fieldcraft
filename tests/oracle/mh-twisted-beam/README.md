# MacNeal–Harder twisted beam

Own analytic quad8 geometry; MITC8, six global DOFs per node. Public reference: MacNeal and Harder, 'A proposed standard set of problems to test finite element accuracy', Finite Elements in Analysis and Design 1 (1985) 3–20, Fig. 6 (p. 8), Table 3 (p. 10). Geometry and loads also illustrated by NASA-CR-192816 (1994), Figs. 3 and 6.

12 by 2 elements; L=12, width=1.1, thickness=0.32, E=29e6, nu=0.22. Root fixed; unit tip-centre forces in Z (in-plane) and Y (out-of-plane). Reference is the corresponding component, not displacement magnitude.

Linear small-displacement benchmark only. Two percent gate; no claim of MITC8/S8R formula equivalence.

The published numerical values are reproduced in a consistent numerical unit system. SI labels here define a similarity-scaled benchmark, not a physical inch/lbf-to-SI conversion of a specimen. Reference displacements are expressed under that same scaling; the reported comparison is the dimensionless displacement ratio.
