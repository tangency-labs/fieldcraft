# Isotropic square frequency

Original full4x4 quad8 square,1m side,h=.01m,E=210GPa,nu=.3,rho7800. Hard simple supports and isolated flexural branch as in the laminate frequency case. Leissa dimensionless frequency2pi² gives f=pi*h*sqrt(E/[12(1-nu²)rho]). Reference is classical thin-plate theory; FSDT rotary/shear effects and mesh error within fixed2%.
