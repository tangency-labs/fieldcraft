# Bryan flat plate buckling

Original full4x4 quad8,1x1m,h=.01m,E1000Pa,nu.3. Unit total compression on x=1, distributed with quadratic edge weights1/6,2/3,1/6. x=0 holds ux; origin holds uy; w all edges,rx xedges,ry yedges; drilling held, other in-plane DOFs free. Linear preload remains flat; geometric stiffness uses its actual MITC membrane stresses. ReferenceNcr=4pi²D. This does not qualify curved-shell or pre-bent laminate buckling, follower pressure or finite rotations.

Independent published reference: [NASA TP-2528 (1986)](https://ntrs.nasa.gov/citations/19860011385), p.10 Table I gives K=4.00 for the isotropic unperforated square (d/W=0). Its uniform displacement preload and the present uniform traction preload give the same uniform membrane stress in this special case. No comparison to cutout cases is claimed. Equation(12) supplies the flat-plate initial-stress energy used here.
