# Harmonic oscillator

Our original one-node spring/mass/dashpot recipe uses SI: m=1, k=4, c=0.04. Frequencies straddle omega=2 rad/s. Direct and all-mode solutions are checked independently against amplitude, phase and input/dissipated power. At zero frequency viscous damping recovers static compliance; a separate eta=0.1 step retains complex compliance, including its imaginary part. No reference numbers came from another solver.
