# Hemispherical shell with an 18° hole under alternating point loads

Own analytic quad8 geometry; MITC8, six global DOFs per node. Public reference: MacNeal and Harder, 'A proposed standard set of problems to test finite element accuracy', Finite Elements in Analysis and Design 1 (1985) 3–20, Fig. 9 (p. 9), Table 5(b) (p. 11): 0.0940 (lower bound 0.0924 from their [7]). Geometry and loads also illustrated by NASA-CR-192816 (1994), Figs. 3 and 6.

12 by 12 elements on a quarter hemisphere, radius 10, thickness 0.04, E=6.825e7, nu=0.3; 18 degree polar opening. Equatorial ring and hole edge free, meridian symmetry, one axial datum. Unit alternating radial corner forces. Probe loaded X component; this is a point-loaded hemisphere, not external-pressure buckling.

Linear small-displacement benchmark only. Two percent gate; no claim of MITC8/S8R formula equivalence.

The published numerical values are reproduced in a consistent numerical unit system. SI labels here define a similarity-scaled benchmark, not a physical inch/lbf-to-SI conversion of a specimen. Reference displacements are expressed under that same scaling; the reported comparison is the dimensionless displacement ratio.
