# Source-bound 5R
Original FieldCraft Hex20 30x6x6, 5593 nodes/1080 elements. L10m, square2m; E2e11Pa, nu.3, rho8000. End-face uy/uz fixed; left center ux fixed. Top pressure .5Pa gives q=1N/m and10N total; fully correlated S_q=1e12(N/m)^2/Hz,0..1000Hz,16 modes,zeta.02. Frozen shared2688-point grid. All model data and commands are in recipe.json, no project filesystem paths, environment variables or skipped test dependency.
Reference: NAFEMS, Selected Benchmarks for Forced Vibration, R0016, 1989, Test 5R. The displacement peak PSD 180.90 mm²/Hz and peak frequency 42.65 Hz are NAFEMS target values, not results of a commercial solver run. Only these published target values are used; no commercial input or private commercial results are used. Peak PSD target1% remains a known failure at ~1.68%; frequency tolerance0.2% is independently scoped. No RMS public reference is invented.
Hex20 displacement grid stabilization does not establish modal truncation or support equivalence. Axial locator mode drifts with refinement; retained highest mode ~587Hz below1000Hz. No stress oracle claimed: old element-side and averaged nodal recovery are not identical definitions. Original Hex8 and withdrawn S09 values are not fixtures here.
