# Unified version 06 fixtures

These four original built-in model fixtures are regenerated by the merged native
engine with the explicit `FC-P4A-UNIFIED-1` result layout. Generator:

`cargo test -p fieldcraft-engine --lib cmd::file::tests::write_the_results_fixtures -- --ignored --exact`

Models: static/modal cantilever, nonlinear contact blocks, heated fluid Couette,
and explicit impact. These are code-defined models, not commercial/project data.
The generator runs the small models and saves through the ordinary native writer;
it does not patch header or kind bytes. Both pre-merge unmarked 06 producer files
remain in git history and in the integration's local evidence archive. They are
not current reader fixtures: their provenance must be established for recovery.
The unchanged MCRSLT05 directory continues to test original compatibility.
