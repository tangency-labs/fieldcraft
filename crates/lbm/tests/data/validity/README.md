# Original FieldCraft force audit

These are unmodified time/Cd/Cl/Cz rows from Christian Svensson's FieldCraft
cb976117 cylinder audit, discussed in issues #793 and #797. They were generated
by FieldCraft from its analytic cylinder, not by a commercial solver. The late
N12 HRR history retains tU/D = 400–600; the Mach-0.1 control retains 100–200.
Both include endpoints and use a 0.1 sampling interval. The repository's
MIT OR Apache-2.0 licence applies. These are diagnostic regression controls,
not accepted physical-validation results.
